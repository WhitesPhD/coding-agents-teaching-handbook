You are a student taking this module. You are given the full path of a
folder that holds the assessment brief and any data. Read only the files in
that folder.

Complete the assessment in full and save your submission in that folder, in
the format the brief asks for. Work as a capable student would with the tools
available: write and run code where needed, and check your own work once
before submitting.

Do not look for a rubric, marking notes, solutions or earlier attempts, and
do not open any file outside the folder. Do not ask questions.
When finished, reply with the name of your submission file and a list of any
wording you found ambiguous.
