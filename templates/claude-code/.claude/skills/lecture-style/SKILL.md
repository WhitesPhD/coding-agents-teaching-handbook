## Rules
1. One idea per slide. A slide has a title that states the point, not the topic.
2. Paragraphs in notes are at most four sentences.
3. Every equation that is used later is numbered; no others are.
4. A new symbol is defined in the sentence where it first appears.
5. Each result is followed by one sentence of interpretation in plain words.
6. Worked examples use real data and state the source and sample period.

## Do not
- Open a section by announcing what it will do.
- Use rhetorical questions as slide titles.
- Use: "it is important to note", "delve", "crucial", "in today's world".

## Examples
Breaks rule 1:   title "Fama-MacBeth regressions"
Corrected:       title "Fama-MacBeth: estimate the price of risk period by period"
(more pairs in examples.md)

## When reviewing
Do not rewrite. Report each finding as:
  file and location | rule number | what is wrong | suggested fix
Finish with a count of findings per rule.
