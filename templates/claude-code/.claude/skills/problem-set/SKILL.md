---
name: problem-set
description: Draft a problem set with verified solutions for one week of the module.
---

Write a problem set for $ARGUMENTS.

1. Read CLAUDE.md, the lecture notes for that week, and two past problem sets
   in problem-sets/ as the standard for style and difficulty.
2. Propose a one-page plan: each question, the outcome it tests, the expected
   time, and whether it is mechanical, applied or stretch. Wait for approval.
3. Write questions.tex, solutions.tex and solve.py in a new folder.
4. Run solve.py. Take every number in solutions.tex from its output.
5. For derivations, verify each final expression symbolically or numerically.
6. Compile both .tex files and fix any errors.
7. Report: what was produced, what was verified and how, and anything you
   could not verify.

Do not reuse or paraphrase questions from textbooks in sources/.
