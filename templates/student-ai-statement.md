Problem sets and labs (not assessed). Any use is permitted. You will learn
more by attempting each question before asking a tool, and the exam tests the
same methods without one.

Coursework (40%). You may use AI tools to find and fix errors in your code
and to check spelling and grammar. You may not use them to:
- write or rewrite any part of the interpretation, discussion or conclusion;
- choose the method, the specification or the data;
- produce tables or figures that your own code did not generate.

Declaration. End your submission with a short paragraph naming each tool you
used and what you used it for, for example: "I used [tool] to find an
indexing error in the code for Table 2. I did not use AI tools for any other
part of this work." [State how a missing declaration is treated.]

Responsibility. You are responsible for everything you submit, including
errors, invented references and copied material introduced by a tool.

Verification. Any student may be asked to explain their submission in a short
conversation with the module team. [State how students are selected and how
the conversation is used, following school policy.]

Exam (60%). Invigilated. No AI tools.
