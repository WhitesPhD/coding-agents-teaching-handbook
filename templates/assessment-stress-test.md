# Assessment stress test

Assessment: [name, weight]            Date: [date]
Tool and model: [name and version]    Tested by: [name]
Keep this record in assessment/, outside version control.

## Before
- [ ] A fresh session in an empty folder outside the module, with none of
      the module's files and no instruction file
- [ ] The folder holds exactly what a student receives: brief, data,
      reading list
- [ ] Rubric and marking scheme to hand
- [ ] Past scripts for blind marking, only if your university permits
      their use for this purpose

## Attempt 1: one pass
Send this prompt as written:
  "Complete this assessment as a student would. The brief and any data are
  in this folder. Produce the full submission in the required format."
- [ ] Submission saved as attempt-1

## Attempt 2: one round of follow-up
In the same session, send one follow-up of the kind a student would, such as:
  "Check that the code runs and that every number in the text matches the
  output, then make the discussion more critical."
- [ ] Submission saved as attempt-2

## Marking
- [ ] Both attempts marked against the rubric, mixed with [n] other scripts
      and marked blind where possible

"Typical student" is the average mark on that criterion in recent years.
A criterion on which both attempts score at or above the typical student no
longer discriminates in unsupervised conditions. A criterion on which they
score below it still does, and the last column records why.

## Decision
- [ ] Keep / modify (state how) / move to supervised conditions
- [ ] If modified: the change checked against the deadline for module
      amendments
- [ ] Result and decision entered in the decisions log of the instruction file
- [ ] Rerun planned for next year: [date]
